# Front-end do Larós MKT

### Como rodar o projeto?

Rode o seguinte comando no seu terminal:

### 1. Instale as dependências do projeto.

bash
```
npm install
```

### 2. Adicione o endereço do back-end no arquivo .env-example (arquivo que está na raiz do projeto) e renomei para .env apenas.

### 3. Rode a aplicação com:
bash
```
npm run dev
```

Esse projeto precisa de Node na versão 18 ou superior.
